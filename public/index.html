Everything a production server needs

Built around real deployments: marketing sites, Next.js frontends and Laravel APIs on the same VPS.

Sites & runtimes

Static, PHP (multiple versions per server) and Node.js sites with aliases, subdomains and isolated PHP-FPM pools per site.

Git deployments

Atomic releases with one-click rollback for Laravel and Node.js. Monorepos and private repositories supported.

Databases

MySQL, MariaDB and PostgreSQL with import, export and automatic safety backups before risky changes.

Automatic SSL

Let's Encrypt certificates with a DNS preflight check before issuing, plus monitored renewals.

Authoritative DNS

Manage zones and records from the panel. New sites can publish their own DNS records automatically.

Encrypted backups

Scheduled full-site snapshots with checksums, encrypted copies to any S3-compatible storage and guided restore.

Laravel ready

Queue workers, scheduler, environment vault and log viewer — managed per site, refreshed on every deploy.

Files, SFTP & cron

Built-in file manager, isolated SFTP accounts per site that work with FileZilla, and scheduled tasks.

Secure by design

A control panel holds the keys to your server. Deneb is built so a bug in the web interface can't become root access.

  • No root daemon. The panel runs as a restricted account; privileged work goes through small, allow-listed helpers.
  • Encrypted secrets. Environment variables, Git tokens and storage keys are encrypted at rest and never shown again.
  • Safe updates. Updates are built and tested before switching, with automatic rollback if the panel doesn't come back healthy.
  • Isolated sites. Each site gets its own PHP identity, temporary directories and SFTP jail.
